# 소스코드 인코딩 변환기

## 프로젝트 개요

팀 프로젝트에서 발생하는 소스코드 인코딩 문제를 해결하기 위한 MFC 기반 GUI 도구입니다.

### 개발 배경
- **팀 프로젝트**: Visual Studio 2015 기반 MFC 프로젝트
- **개발 환경**: 대부분 팀원은 VS 2022 사용
- **기존 소스코드**: ANSI(CP949) 인코딩
- **개인 작업**: CLI 툴 사용으로 UTF-8 필요
- **발생 문제**:
  - ANSI와 UTF-8 혼용 시 한글 주석 깨짐
  - 코드 손상 발생
  - 협업 충돌 빈발

## 주요 기능

### 인코딩 감지 및 스캔
- **지원 인코딩**: UTF-8 BOM, EUC-KR(CP949), ANSI
- **파일 형식**: C/C++ 소스/헤더, 리소스 파일(.rc), 텍스트 파일 등
- **재귀 스캔**: 하위 디렉토리 포함
- **실시간 통계**: 인코딩별 파일 개수 표시

### 스마트 변환 시스템
- **UTF-8 변환**: ANSI/EUC-KR → UTF-8 BOM
- **원본 복원**: 변환 기록 기반으로 정확한 원본 인코딩 복원
- **백업 생성**: 변환 실패 시 자동 복원
- **일괄 처리**: 대량 파일 고속 처리

### 변환 기록 관리
- **기록 저장**: 원본 인코딩 정보를 UTF-8로 자동 저장 (`D:\EncodingConversionRecord\EncodingConversionRecord.txt`)
- **메모리 캐시**: 고속 조회를 위한 인메모리 처리
- **스마트 복원**: 기록 기반 정확한 원본 인코딩 복원
- **성능 최적화**: 2000개+ 파일도 빠른 처리

## 사용법

### 1. 파일 스캔
1. "찾기" 버튼으로 스캔할 디렉토리 선택
2. "스캔" 버튼으로 인코딩 분석 실행
3. 결과 리스트에서 파일별 인코딩 확인

### 2. UTF-8 변환
1. "UTF-8로 변환" 버튼 클릭
2. ANSI/EUC-KR 파일들이 UTF-8 BOM으로 변환
3. 원본 인코딩 정보 자동 저장

### 3. 원본 복원
1. "EUC-KR로 변환" 버튼 클릭 (원본 복원)
2. 변환 기록을 참조하여 정확한 원본 인코딩으로 복원
3. 기록이 없는 파일은 자동 건너뜀

## 기술 스택
- **Framework**: MFC (Microsoft Foundation Classes)
- **IDE**: Visual Studio 2015+
- **Platform**: Windows
- **Language**: C++
- **Encoding**: UTF-8 BOM, EUC-KR(CP949), ANSI

## 프로젝트 구조
```
Encoding/
├── Encoding.cpp           # 메인 애플리케이션
├── EncodingDlg.cpp        # 메인 다이얼로그
├── EncodingDlg.h          # 다이얼로그 헤더
├── Encoding.rc            # 리소스 파일
└── resource.h             # 리소스 헤더
```

변환 기록 파일은 프로그램 실행 시 자동 생성됩니다:
```
D:\EncodingConversionRecord\EncodingConversionRecord.txt
```

## 빌드 방법
1. Visual Studio 2015 이상에서 프로젝트 열기
2. x64 Debug/Release 구성으로 빌드

## 성능 특징
- **메모리 캐시**: 변환 기록을 메모리에 로드하여 고속 처리
- **UTF-8 레코드 파일**: 한글 경로 포함 모든 경로를 손실 없이 저장/복원
- **대용량 처리**: 2000개+ 파일도 빠른 변환/복원

## 활용 시나리오

### 개인 작업 시
```
팀 소스 다운로드 (ANSI) → UTF-8 변환 → CLI 도구 작업 → 원본 복원 → 커밋
```

### 협업 워크플로우
1. **작업 시작**: ANSI 소스를 UTF-8로 변환
2. **개발**: CLI 도구, 외부 에디터 사용
3. **작업 완료**: 원본 ANSI로 복원
4. **커밋**: 팀원들과 동일한 인코딩 유지
